# 专注钟与打卡热力图小程序

一个记录每日专注时长的微信小程序，核心功能是「正向计时专注钟 + 月历式打卡热力图」。

> 《人工智能基础与应用》课程作业 · 借助 AI（GLM）辅助开发

## 功能特性

### ⏱ 专注计时
- **正向计时**：显示已专注时长，无倒计时压迫感
- **目标时长**：预设 25 / 45 / 60 分钟，支持自定义目标（1~600 分钟），可编辑、删除预设
- **不限时模式**：自由专注，随时结束
- **全屏横屏专注**：一键 CSS 旋转横屏，纯黑背景只保留超大计时数字，点按屏幕呼出操作
- **达标提醒**：达到目标时长时震动 + 铃声 + 横幅提示
- **休息提醒**：每连续专注 1 小时提醒休息（间隔内不含暂停时间），可暂停休息后继续计时
- **状态恢复**：小程序被杀后 6 小时内重新打开可恢复计时

### 📝 专注记录
- **专注标签**：学习 / 阅读 / 工作 / 运动，支持自定义标签，可编辑、删除（含自带标签）
- **专注描述**：结束后可记录本次专注内容
- **未完成原因**：未达标结束时记录原因，便于回顾分析
- **暂停记录**：记录累计专注时长，暂停期间不计入

### 📅 打卡热力图
- **月历式热力图**：按月展示每日专注强度，5 级绿色深浅
- **翻月浏览**：支持回看最近 12 个月
- **本月概览**：总时长 / 打卡天数 / 最长单日 / 平均时长
- **单日明细**：查看任意一天的标签、时段、时长、状态与描述

### 📊 数据统计
- 累计专注、本周专注、连续打卡等指标
- 近期柱状图、标签分布
- 最近 10 条记录列表
- **打卡分享卡片**：Canvas 生成 600×960 分享图

### 🎨 其他
- 深色模式开关（自定义导航栏，全局主题变量）
- 本地存储，数据持久化（数据层已抽象，可无缝切换云存储）

## 使用方式

1. 用微信开发者工具「导入项目」，选择本目录（appid 用测试号即可）
2. 编译预览即可体验全部功能

## 技术要点

- 原生微信小程序开发，无第三方框架依赖
- CSS 主题变量实现深浅色全局切换
- CSS `transform: rotate` 实现伪横屏全屏（无需页面方向配置）
- Canvas 绘制进度圆环与分享卡片
- Python 标准库生成 PNG 图标与 WAV 提示音（`tools/`）
